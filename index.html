Configuração do modo edição

O repositório onde estão este site e o data.json.

É o que deixa você adicionar, editar e remover pelos painéis abaixo — sem ele o site fica só de leitura.
Gere em github.com/settings/personal-access-tokens/new → Fine-grained → Only select repositories → este repo → Repository permissions → Contents: Read and write. Coloque uma validade (90 dias). Nunca use em computador compartilhado.

verificando…

themoviedb.org → conta → Settings → API → chave "Developer". Sem ela dá pra digitar título/diretor/ano à mão.

Adicionar filme ao diário

Busca o filme na base do TMDB (ou preencha à mão) e salva direto no data.json. Aparece na hora.

Isto é um diário, não uma vitrine.

Comecei este registro para me obrigar a ver mais filmes — e a prestar atenção no que via. Cada coleção nasce de uma pergunta que eu mesmo estava tentando responder assistindo.

As notas são escritas logo depois de assistir. Deixo aberto porque impressão de cinema rende mais compartilhada do que guardada numa gaveta — mas o critério aqui é sempre pessoal.
