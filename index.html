Configurações (uma vez só)
verificando…

Pegue grátis em themoviedb.org → crie uma conta → Settings → API → solicite uma chave "Developer". Sem isso a busca automática de filmes não funciona.

É pra onde os botões "Adicionar" abaixo vão te mandar, com o formulário certo já aberto.

Adicionar filme ao diário

Busca o filme numa base de dados real e abre um formulário do GitHub já preenchido — você só confirma o envio, sem editar código.

Abre uma aba nova já preenchida. É só clicar em "Submit new issue" — o site atualiza sozinho em cerca de 1 minuto.

Coleções

Curadoria por afinidade

Grupos de filmes que respondem a uma pergunta específica — não um gênero, não uma década.

Criar nova coleção

Cria a coleção vazia — depois use o painel abaixo pra ir adicionando filmes a ela, um de cada vez.

Depois de enviado, o robô cria a coleção e responde na própria issue com o id gerado — ele já aparece nos menus abaixo em cerca de 1 minuto.

Adicionar filme a uma coleção

Busca o filme numa base de dados real e abre o formulário do GitHub já preenchido.

É só confirmar o envio na aba que abrir — o filme entra na coleção sozinho.

Bastidores

Arquivo de vídeos

Vídeos que inspiraram uma coleção ou um filme específico — filtre pra ver só o que se relaciona ao que você está lendo.

Adicionar vídeo de referência

Cole o link do YouTube, busque os dados automaticamente e relacione a uma coleção e/ou a um filme específico.

Confirme o envio na aba que abrir — o vídeo entra no arquivo sozinho.

Isto é um diário, não uma vitrine.

Comecei este registro para me obrigar a ver mais filmes — e a prestar atenção no que via. Cada coleção nasce de uma pergunta que eu mesmo estava tentando responder assistindo.

As notas são escritas logo depois de assistir. Deixo aberto porque impressão de cinema rende mais compartilhada do que guardada numa gaveta — mas o critério aqui é sempre pessoal.
